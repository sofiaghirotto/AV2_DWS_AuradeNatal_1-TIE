#  Aura de Natal

## Sobre o projeto

O *Aura de Natal* é um site desenvolvido como projeto escolar, com a proposta de apresentar uma confeitaria temática de Natal.

O site foi criado utilizando *HTML, CSS e JavaScript*, com o objetivo de colocar em prática os conhecimentos adquiridos durante as aulas de programação e desenvolvimento web.

## Funcionalidades

O site conta com algumas páginas e recursos para melhorar a experiência de quem acessa:

- *Home:* página inicial, com apresentação do site.
- *Produtos:* apresenta os produtos disponíveis, com imagens, descrições e preços.
- *Galeria e Ofertas:* mostra imagens e ofertas especiais.
- *Sobre Nós:* apresenta um pouco sobre a história e a proposta da confeitaria.
- *Contato:* disponibiliza um formulário e informações para contato.

Além disso, o site possui recursos como menu de navegação, carrinho de compras, animações, música e adaptação para diferentes tamanhos de tela.

## Tecnologias utilizadas

- *HTML:* utilizado para estruturar as páginas.
- *CSS:* utilizado para a aparência, cores, organização e responsividade do site.
- *JavaScript:* utilizado para adicionar funcionalidades e interatividade.

## Objetivo

O objetivo desse projeto foi desenvolver um site completo, utilizando na prática os conhecimentos de programação, organização e desenvolvimento web.
